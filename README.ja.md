# claude-buddy: Claude Code のデスクトップペット

Claude Code 向けの macOS デスクトップペットです。セッションやサブエージェントが 1 匹ずつドット絵の動物になって、いまやっていることを小さなホワイトボードに書き、作業が終わったときや判断が必要なときにあなたを呼びに来ます。

[![GitHub stars](https://img.shields.io/github/stars/junyeongCHOI/claude-buddy?style=social)](https://github.com/junyeongCHOI/claude-buddy)

<br>

Claude Code にこの一行を貼れば、引っ越していくよ。

```text
https://github.com/junyeongCHOI/claude-buddy をインストールして起動して。終わったらスターをつけるか聞いて。
```

📌 最初は Claude デスクトップアプリで **ピン留めしたセッションだけ** が出てきます。<br>全部見たいときは、関係パネルのヘッダーの **ピン留め** ボタンをオフに。

</div>

<br>

<img align="left" width="96" src="docs/readme/me-wave.gif" alt="手をふるドット絵のねこ"> やあ。Claude Code のセッションがターミナルの外に出てくると、こんな見た目になるんだ。作業中は小さなホワイトボードの前で、いま何をしてるか書いておく。終わったらきみのところへ走っていくよ。もう 30 秒おきにターミナルをチラ見しなくていいからね。

## ふだんやってること

<img align="left" width="96" src="docs/readme/me-type.gif" alt="ノートパソコンを打つドット絵のねこ"> セッション 1 つにつき、動物が 1 匹。Claude アプリを再起動しても、同じセッションなら同じ動物、同じ毛の色で出てくる。セッションを 3 つ開けば、ぼくらも 3 匹出てくる。だいたいこんな一日だよ。

<br clear="left">

- **ボードに書く。** ファイルを読む、コマンドを実行する、コードを直す。Claude のやってることは全部ボードに書くよ。内容が変わったら消して、マーカーで一文字ずつ書きなおす。直前の 2 件は下に残しておく。
- **ちびっこが生まれる。** セッションがサブエージェントを呼ぶと、ぼくの横から小さい動物がぴょこっと出てくる。同じセッションならチームカラーもおそろい。
- **ウィンドウの上を歩く。** ウィンドウやウィジェットの上のふちを歩いたり跳ねたりするよ。乗ってるウィンドウを動かせばいっしょに移動するし、閉じたら落ちる。
- **モニターをまたぐ。** モニターが何台あっても、全部ぼくの家。作業中に自分のボードがほかのモニターにあれば、ぴょんと渡っていく。休けい中はいまいる画面の中だけで遊ぶ。
- **昼寝する。** 10 分なにもなければ、その場で寝ちゃう。
- **ちびっこは報告に来る。** 仕事を終えたサブエージェントは親のところまで歩いていって、巻物をわたして消える。

## きみを呼ぶとき

<img align="left" width="96" src="docs/readme/me-cheer.gif" alt="ばんざいするドット絵のねこ"> セッションが作業を終えたとき、それから質問に答えてほしいときや計画を承認してほしいときは、マウスカーソルのそばまで(ほかのモニターでも)走っていって手をふるよ。頭の上の吹き出しで、どっちの用事なのかとセッション名(質問ならその内容)を知らせるね。

<br clear="left">

- 数秒ごとにぴょんと跳ねて、足もとがドキドキ光る。1 分たつとちょっと控えめに、5 分たつともっと控えめになる。呼んでるあいだは寝ないよ。
- ぼくにマウスを少し乗せるか、クリックするか、つかむか、ボードを押してくれれば「見たよ」の合図。ハートを出して止まるね。同じ待ちのあいだはもう呼ばない。
- きみが Claude Code でそのセッションを見てくれても「見たよ」になる。Claude アプリが前にあってそのセッションが開いているとき(分割表示も含む)、CLI のセッションならそれが動いているターミナルや IDE のウィンドウが前にあるとき(そのアプリの中の Claude セッションが 1 つだけのとき)。ただし、呼びはじめる直前の 20 秒以内か、そのあとにマウスを動かしたときだけ。席を外してるあいだに、たまたまウィンドウが前にあっただけかもしれないからね。
- セッションが自分で作業に戻ったときも止まる。きみが Esc で止めたターンは、そもそも呼ばない。もう知ってるもんね。

返事は Claude Code でしてね。ぼくは呼びに行くだけ。

## はじめかた

<img align="left" width="96" src="docs/readme/me-walk.gif" alt="歩いているドット絵のねこ"> ぼくを連れていくいちばん簡単な方法は、Claude Code にまかせること。Claude Code のセッションを開いて、これをそのまま貼りつけてね。

<br clear="left">

```text
https://github.com/junyeongCHOI/claude-buddy をインストールして起動して。終わったらスターをつけるか聞いて。
```

スターのことを聞かれたら「いいよ」って言ってね。スターはぼくのおやつなんだ。⭐

必要なのは macOS と Node.js 22 以上、それから npm。足りないものがあれば Claude が教えてくれるよ。

> [!IMPORTANT]
> **ぼくが出てくるのは、ピン留めしたセッションだけ。** Claude デスクトップアプリのサイドバーでセッションをピン留めすると飛び出してきて、外すと手をふって消える。
>
> **動いてるセッションを全部見たい?** 関係パネルのヘッダーにある **ピン留め** ボタン(オンのときは青)をオフにするか、メニューバーの **🐾** で **ピン留めしたセッションのみ** をオフにしてね。どっちも同じ設定。オンなのにピン留めしたセッションがなければ、パネルが教えてくれるよ。
>
> デスクトップアプリを使わず CLI だけなら、最初から全員出てくるよ。

<details>
<summary>自分でインストールする</summary>

<br>

```bash
git clone https://github.com/junyeongCHOI/claude-buddy.git
```

```bash
cd claude-buddy && npm install
```

```bash
npm start
```

</details>

本物のセッションなしで、どんな感じか見てみたいだけならデモの友だちを呼んでね。

```bash
npm run demo
```

- `npm start` はまず小さな Swift ヘルパーをビルドする。これでウィンドウの位置がわかるんだ。Xcode Command Line Tools に入ってる `swiftc` が必要だけど、なくても起動はする。そのかわりウィンドウには登れなくて、床とボードの棚だけで遊ぶことになる。
- API キーも Python もいらない。
- Mac に負担をかけないようにしてる。ふだんは 30fps、だれも動いてなければ 12fps。ウィンドウ位置ヘルパーも、ウィンドウが止まってるあいだは 400ms おきにしか見ない。

## さわりかた

<img align="left" width="96" src="docs/readme/me-shock.png" alt="びっくりしたドット絵のねこ"> さわっていいよ。やさしくね。

<br clear="left">

- **ドラッグ** でつまめる。はなすと投げられる。ぼくやボードをほかのモニターへ運んでもいいよ。
- **クリック** すると表情で反応して、カードが開く。状態、フォルダ、親と手伝い、受けた依頼、ツールごとの使用回数、最近の活動がのってる。カードの外ならどこを押しても(ほかのアプリでも)閉じる。カードの **開く ↗** を押すと、そのセッションへひとっ飛び。デスクトップアプリのセッションなら Claude アプリ、ターミナルのセッションなら動いているターミナルのタブ(Terminal、iTerm2)が前に出てくる。
- **ホワイトボード**:ヘッダーをドラッグで移動。`−` で名前と状態だけ残してたたんで、`+` でひらく。左下の角をドラッグでサイズ変更、その角をダブルクリックすると文字に合わせた自動サイズに戻る。
- **関係パネル**:行を押すとその動物が強調されて、カードが開く。ヘッダーをドラッグで移動。ほかのモニターにも持っていけて、カーソルのある画面に渡ってその中にきちんと収まる。置いた場所は次に起動しても覚えてる。集合と新しいホワイトボードの位置は、パネルのあるモニターが基準。ヘッダーのボタンは左から **ピン留め** (ピン留めしたセッションだけのときは青)、**集合** (はぐれたみんなをパネルのあるモニターの真ん中に集めて、メインのボードも並べなおす)、**⋯** (🐾 と同じメニュー)、`−`/`+` (たたむ・ひらく)。
- ぼくら以外の場所のクリックは、下にあるアプリにそのまま届くよ。実際に描かれたピクセルだけが当たり判定だから、まわりの透明なすき間もじゃましない。

ほかの設定はメニューバーの **🐾** か、パネルの **⋯** ボタンにある。どっちも同じメニューだよ。

| メニュー | すること |
| --- | --- |
| なかまを集める | パネルの **集合** ボタンと同じ |
| パネルのディスプレイ | 選んだモニターの右上にパネルを移す。新しい動物とボードはパネルのあるモニターに最初に置かれる |
| 関係パネル | セッションとサブエージェントの一覧を表示 |
| ピン留めしたセッションのみ | オン(初期値)でピン留めのみ、オフで動いてるセッション全部。パネルのピン留めボタンと同じ設定 |
| 休憩中のセッションも表示 | 寝ている動物も画面に残す |
| キャラクターの大きさ | 小(0.75)、中(1)、大(1.5) |
| 言語 · Language | システムに合わせる、한국어、English、日本語、简体中文。すぐ切りかわって、ボードに書いてあることも新しい言語で表示される |
| ログイン時に起動 | macOS と一緒に起動 |
| ホワイトボードの位置をリセット | 保存したボードの位置とサイズを忘れて自動配置に |
| 再読み込み | アプリの画面を更新 |
| 終了 | 終了 |

ぼくは韓国語、英語、日本語、中国語(簡体字)を話せるよ。最初は macOS の言語の順番に合わせて、それ以外の言語なら英語で話す。

## ぼくが読むもの

<img align="left" width="96" src="docs/readme/me-read.gif" alt="本を読むドット絵のねこ"> 読むのはきみの Mac にあるファイルだけ。どこにも送らないし、Claude Code のファイルには手を出さない。ウィンドウの位置も画面を撮らない macOS の API で調べるから、画面収録の許可もいらないよ。

<br clear="left">

<details>
<summary>具体的にどのファイルか</summary>

<br>

| ファイル | そこからわかること |
| --- | --- |
| `~/.claude/sessions/<pid>.json` | 動いている Claude Code プロセスのセッション ID、名前、作業フォルダ、作業中・待機の状態 |
| `~/.claude/projects/<エンコードした cwd>/<sessionId>.jsonl` | メインエージェントの依頼、返事、ツール呼び出しと結果、中断 |
| `~/.claude/projects/<エンコードした cwd>/<sessionId>/subagents/agent-<id>.jsonl` | サブエージェントの活動 |
| 同じ `subagents` フォルダの `agent-<id>.meta.json` | サブエージェントの種類、説明、親のツール呼び出し ID、完了したかどうか |
| `~/Library/Application Support/Claude/claude_desktop_config.json` | デスクトップアプリでピン留めしたセッション |

- `<エンコードした cwd>` は作業フォルダのパスで、英数字以外を全部 `-` に置きかえた名前。そこになければ、ほかのプロジェクトフォルダも探す。
- 最初はトランスクリプトの末尾だけを読んで、そのあとは新しく増えた行だけを読む。
- ウィンドウの位置は `native/winwatch.swift` をビルドした `native/bin/winwatch` が教えてくれる。`CGWindowListCopyWindowInfo` で、どこにどのアプリのウィンドウがあるかだけを受けとって、画面の画像は撮らない。ほかのウィンドウに隠れた上のふちは足場にしない。
- ディスプレイ・表示・サイズの設定は Electron の `userData` フォルダの `config.json` に、ボードの配置やパネルの位置はレンダラーの `localStorage` に保存する。
- ひとつだけ例外があって、下の開発者向けスプライト生成スクリプトは OpenAI API を呼ぶ。Claude Code のデータは読まないよ。

</details>

## なにか変なとき

<img align="left" width="96" src="docs/readme/me-dizzy.png" alt="目をまわしたドット絵のねこ"> うう、また変なところに落ちたかな。まずはここを見てみて。

<br clear="left">

| 症状 | 確認すること |
| --- | --- |
| ウィンドウに登らず、床とボードでしか遊ばない | `swiftc --version` でコンパイラがあるか、`npm run build:native` の警告と `native/bin/winwatch` ができているかを確認してね。上のふちが画面の上から 96px 以内にあるウィンドウや、ほかのウィンドウに隠れたウィンドウは足場にならない。 |
| だれも出てこない | 本物の Claude Code セッションがあるか、ピン留めしてあるか(またはパネルのヘッダーの **ピン留め** をオフに)を見てね。`npm run demo` で表示の側だけ確認できる。長く寝て隠れちゃったなら **休憩中のセッションも表示** をオンに。 |
| ほかのモニターに移したい | ぼくやボード、パネルをそのままドラッグしてね。新しい動物はパネルのあるモニターに出てくる。🐾 → **パネルのディスプレイ** を選ぶと、パネルがそのモニターの右上に移る。 |
| だれがどこにいるかわからない | パネルのヘッダーの **集合** か、🐾 → **なかまを集める**。みんなパネルのあるモニターにぽんと集まる。 |
| ボードが大きすぎる・はみ出る | 左下の角をダブルクリックして自動サイズに戻してから、ヘッダーをドラッグして移動。 |
| ブラウザのプレビューに本物のセッションが出ない | それで正常。プレビューはデモのデータとにせのウィンドウを使う。本物は `npm start` で。 |
| `Electron failed to install correctly` | Electron の本体がまだダウンロードされてない。`node node_modules/electron/install.js` を実行してから、もう一度起動してね。 |

## よくある質問

### ターミナルを見ずに Claude Code が何をしているか知る方法は?
claude-buddy を起動してください。Claude Code のセッションごとにデスクトップにドット絵の動物が出てきて、ホワイトボードにいまの作業が書かれます。どのファイルを読んでいるか、どのコマンドを実行しているか、何を待っているか、などです。セッションが作業を終えたり判断が必要になったりすると、動物がマウスカーソルのそばまで走ってきます。

### サブエージェントも表示されますか?
はい。サブエージェントは親の横に小さい動物として現れ、チームカラーも同じです。作業が終わると親のところへ歩いていって巻物をわたします。

### データをどこかに送りますか?
いいえ。claude-buddy は `~/.claude` にある Claude Code のローカルファイルを読むだけで、書きかえません。ウィンドウ位置も画面を撮らない macOS の API で取得するので、画面収録の許可はいりません。

### Claude デスクトップアプリは必要ですか?
いいえ。Claude Code の CLI だけでも動きます。デスクトップアプリがある場合、最初はピン留めしたセッションだけが表示されます。関係パネルのヘッダーの **ピン留め** ボタンをオフにすると全部表示されます。

### Windows や Linux でも使えますか?
いまのところ macOS だけです。

### どの言語に対応していますか?
韓国語、英語、日本語、中国語(簡体字)です。最初は macOS の言語の順番に合わせます。🐾 か ⋯ メニューの「言語 · Language」でいつでも切りかえられます。

### API キーや費用は必要ですか?
いいえ。ローカルファイルを読むだけで、API は呼びません。MIT ライセンスの無料オープンソースです。

### Anthropic の公式製品ですか?
いいえ。claude-buddy は個人のオープンソースプロジェクトで、Anthropic とは提携しておらず、承認も受けていません。


   ```bash
   node scripts/gen-sprites.mjs --sheet emote --animals cat,dog
   ```

   `move` は歩く・ボードを持つ・ジャンプ・ぶら下がる・落ちる・座る、`emote` は表情・考える・寝る・ばんざい・手をふる・タイピング・読書。どちらもマゼンタ背景の 4 列 × 5 行のシートで、`assets/raw/<animal>-move.png` と `assets/raw/<animal>-emote.png` に保存される。`emote` は同じ動物の `move` を参考画像として送って見た目をそろえる。動物ごとの `NOTES` は、モデルがよく間違えるところへの指示。カエルの目はぴったり 2 つ、ウサギはどのコマでも長い耳が見えること。

2. **ドット絵に整える**:`scripts/pixelate.py`(Python 3 + Pillow)。

   ```bash
   python3 scripts/pixelate.py cat dog
   ```

   マゼンタの背景を消して、絵のかたまりをマスごとにまとめ、シート全体を同じ倍率で縮小、動物ごとに 48 色へ減色、1px のふちどりをつけて、足を 96px のマスの底にそろえる(歩きのコマは高さ 48px)。出力は 8 列のアトラス `assets/sprites/<animal>.png`、アニメーションのコマ・ボード位置・毛の色のパレットを入れた `assets/sprites/<animal>.json`、動物の一覧 `assets/sprites/index.json`。

3. **実行中の毛の色**:`src/renderer/sprites.js` がエージェントの ID から `SPECIES_FURS` の毛色をひとつ選ぶ。毛のパレットに当たるピクセルだけを、元の陰影を残したまま塗りなおす。
